## Організація

- `lab1/` — функції, замикання, колекції, рядки, дати.
- `lab2/` — класи, ієрархії, mixin, узагальнення, записи.
- `lab3/` — Future, Stream, ізоляти та модульні тести.
- `lab4/` — модульність, файлова система, HTTP/JSON, shelf, тести.

Кожна лабораторна — окремий Dart package із власними `pubspec.yaml`, `bin/`, `lib/`, `test/` (для ЛР 3–4) та README.

## Запуск та перевірка

Перейдіть у каталог конкретної лабораторної (наприклад `cd lab1`) та виконайте:

```powershell
dart pub get
dart format .
dart analyze
dart run bin/main.dart
```

Для ЛР 3–4 після додавання тестів: `dart test`. Наявність шаблону не означає, що програма задовольняє майбутню індивідуальну умову.

## Залежності

У стартовому шаблоні ЛР 1–2 зовнішні залежності з pub.dev не потрібні: використовується стандартна бібліотека Dart. Для ЛР 3 додано dev-залежність `test` для модульних тестів; для ЛР 4 — `test` і `shelf` як вимогу навчальної програми. Альтернативи та остаточні рішення потрібно обґрунтувати після отримання завдання.
