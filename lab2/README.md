# Лабораторна робота №2

**Тема:** Класи, ієрархії, mixin та узагальнення  
**Індивідуальне завдання:** очікується від викладача.

## Структура

- `bin/main.dart` — точка входу консольного застосунку.
- `lib/` — основна логіка, яку можна повторно використовувати і тестувати.

## Архітектурні рішення

Початковий поділ між `bin/` і `lib/` дозволяє відокремити введення-виведення від логіки. Вибір конкретних типів даних і альтернативи буде описано після отримання індивідуальних вимог.

## Залежності

На старті використовується лише стандартна бібліотека Dart; `lints` — для статичного аналізу.

## Результати перевірки

Поки що не запускались; необхідно вставити фактичний вивід `dart analyze` після реалізації завдання.
